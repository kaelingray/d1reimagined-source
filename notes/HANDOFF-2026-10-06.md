## Attachment-layout candidate

[rpcs3-attachment-layout.patch](../patches/rpcs3-attachment-layout.patch) changes
only `rpcs3/Emu/RSX/VK/VKDraw.cpp` against the exact pre-change private tree:

- Refresh the attachment layout/input key when the renderer begins a pass, after
  late binding transitions. An unchanged key retains the cached pass.
- Restore feedback/general depth layout immediately before the emulated depth-
  compare sampler is bound; the intervening write/fall-out barrier may have changed it.

JOIN154 previously reports stale attachment and sampler layouts, including
`VUID-vkCmdDraw-None-09600` at submission. The source ordering exposes a corresponding
gap; native causality is unproved. Vulkan requires descriptor image layouts to match
and permits render-pass compatibility across layout-only differences. See
[descriptor requirements](https://docs.vulkan.org/refpages/latest/refpages/source/vkCmdDraw.html)
and [render-pass compatibility](https://docs.vulkan.org/spec/latest/chapters/renderpass.html#renderpass-compatibility).

[rpcs3_attachment_layout_audit.py](../scripts/rpcs3_attachment_layout_audit.py)
extracts the actual read validator, key encoding/update, begin/cache methods and
depth-compare binding block. Checks cover forward/reverse transitions, feedback
extension/GENERAL fallback, five attachments, input-mask removal, format/sample
preservation, descriptor agreement and cache reuse. All **31 CPU checks pass**;
the original flow fails **15**. Mocks close passes on layout barriers. They do not
prove pixels, GPU hazards, shader correctness or performance.

Full MSVC x64 Release build passes. Candidate executable SHA-256:
`55efc9072019124be3e880ca8c881339d057390c47d3bf77c799ccb6de920259`.
It is **built, not deployed; native/visual acceptance NOT RUN**. The runtime remains
the compared `5d94...` executable. The one-file patch passes `git apply --check` and
reproduces normalized changed source in a new isolated fixture. Patch SHA-256:
`81d44a20718a516672fe96b56b7b05fbb29aacc287414ce4116a2f7f6150144d`.
This is an increment against the existing private renderer, not a complete stock
patch set. Unrelated private changes are excluded.

Generate a new CPU fixture with
`python scripts/rpcs3_attachment_layout_audit.py --source <private-rpcs3-source> --out <new-private-fixture-directory>`.
Compile its generated C++ with MSVC `/std:c++20 /EHsc /W4` and run the resulting
executable. Backend and script regressions pass 167 and 145 tests; PowerShell
syntax and three data-checkout lookup cases also pass.
