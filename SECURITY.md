# Security reporting

Send a minimal description and affected source version to security@d1reimagined.com. Do not include passwords, access tokens, game files, account data or unnecessary personal information. Use a private report for sensitive findings and wait for coordination before disclosing an exploit.

Only test your own disposable, isolated setup. Never probe third-party accounts, public game services or consoles without their owner's explicit authorisation. This experimental source is not a hardened public multiplayer service.
