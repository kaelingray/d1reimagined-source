# Local service experiments

Original experimental loopback DNS, sign-on, lobby, session and activity-host stand-ins for the retained PlayStation 3 target. Synthetic replies and schema-valid data are not complete account, mission or multiplayer implementations.

Use the root README for dependency setup and regression commands. Private schema inputs, session keys, generated CA materials and databases belong outside source control, under the ignored runtime selected by `D1_LOCAL`. No genuine online identity or public service access is granted by these stand-ins. Keep listeners on loopback and preserve independent containment when running a privately prepared emulator.
